      Orthotic Design — Prototype

      Conceptual workflow only

        Illustrative relief design

        Uses the whole recording: each sensor's peak load (95th percentile over all frames). The sensors with the highest peaks get a circular relief pocket. The insole length is estimated from the participant's shoe size. Depth and thickness are values you choose for demonstration; they have no clinical basis.

        ZonePositionSensorsPeak value

          The design is not clinically safe, validated for any individual, or print-ready. Real orthotic parameters need validated clinical criteria and a labelled patient dataset, which this prototype does not have.

          The selected frame's values with plainly labelled, non-clinical fields.

          Recording report

          One printable page for the loaded recording

          Builds a summary of the loaded recording, its data-quality checks and (if generated) the illustrative orthotic design. Use Print / Save as PDF in the browser's print dialog to keep a copy.
